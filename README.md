# python-projects
This is the python projects repository in this repository I buit 2 python projects. These projects were built to practice and improve my Python programming skills.

1. Jarvis:
JARVIS is a Python-based AI voice assistant that listens for the wake word "Jarvis" through the microphone. Once activated, it records the user's voice, converts speech into text using Speech Recognition, and performs different actions based on the command.

The assistant can:
Listen for the wake word "Jarvis" to activate.
Recognize voice commands using Google Speech Recognition.
Open websites such as Google, YouTube, ChatGPT, and Gemini.
Answer general questions using the Google Gemini API.
Respond with natural-sounding speech using the pyttsx3 text-to-speech engine.
Record audio through the microphone using sounddevice and process it for speech recognition.

Technologies Used:
Python
SpeechRecognition
SoundDevice
SoundFile
pyttsx3
Google Gemini API
Webbrowser
python-dotenv

2. Guess the number:
A simple Python console game built to practice basic programming concepts. In this game, the computer randomly selects a number, and the player has to guess it. The program provides hints such as whether the guessed number is too high or too low until the correct number is found.

Concepts Used:
Python Basics
Variables
Loops
Conditional Statements
Random Module
User Input
